## О проекте

ACM Manager решает реальную проблему инженеров-проектировщиков: каждый раз при смене рабочего места или переустановке AutoCAD приходится вручную искать, скачивать и устанавливать нужные плагины. При этом стандартная папка AutoCAD лежит в `Program Files`, куда без прав администратора не залезть.

Идея простая: сделать десктопное приложение, которое само знает где лежат плагины в корпоративной сети, показывает их список с описанием и устанавливает одним кликом. Без лишних прав, без головной боли.

### Стек технологий

| Слой | Технология |
|------|-----------|
| Frontend | React + Vite |
| Backend | Python + Electron IPC |
| Упаковка | Electron |
| Хранилище | Сетевая папка / HTTP-сервер |

### Целевая аудитория

- Инженеры-проектировщики и архитекторы
- CAD-специалисты в строительных компаниях
- BIM-менеджеры, которые тратят до 15% времени на настройку рабочих мест

### Запись 3 — Создание статического сайта

**Дата:** 13 июня 2026 г.

Основная работа этапа: сверстать сайт про проект ACM Manager на чистом HTML и CSS без фреймворков.

Что сделал:

- Разработал структуру сайта: главная, о проекте, участники, журнал, ресурсы
- Написал все страницы на HTML5
- Сделал общий файл стилей `css/style.css` с тёмной темой
- Реализовал адаптивную вёрстку через CSS Grid и Flexbox
- Настроил навигацию между страницами

Самое сложное было сделать нормальный дизайн без Bootstrap и прочих библиотек. Пришлось разобраться с CSS-переменными, `backdrop-filter` и `clamp()` для адаптивных размеров шрифта. В итоге получилось аккуратно.

Пример использования CSS-переменных в проекте:

```css
:root {
  --bg: #0f0f13;
  --accent: #5b7fff;
  --text: #e2e2f0;
  --radius: 14px;
}
```
