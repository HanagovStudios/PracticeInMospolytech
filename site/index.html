О проекте

Что такое ACM Manager

Десктопное приложение для управления плагинами AutoCAD в корпоративной среде, разработанное в рамках проектной деятельности.

Проблема

Каждый раз при смене рабочего места или переустановке AutoCAD инженер вручную ищет нужные плагины и сталкивается с правами доступа. Стандартная папка AutoCAD лежит в Program Files, куда без администратора не залезть.

  • Сложный поиск плагинов в локальной сети компании
  • Конфликты версий и отсутствие стандартизации
  • UAC-ограничения при установке в Program Files
  • До 15% времени BIM-менеджера уходит на настройку рабочих мест

Решение

  • 1 Открываешь приложение, видишь список плагинов из корпоративного хранилища
  • 2 Читаешь описание, смотришь версию
  • 3 Нажимаешь установку — плагин копируется в AppData без прав администратора
  • 4 Перезапускаешь AutoCAD, плагин уже работает
📦

Установка плагинов

Копирует .bundle-папку в %APPDATA%\Autodesk\ApplicationPlugins. Никаких прав администратора.

📋

Каталог из сети

Подключается к сетевой папке компании и показывает список доступных плагинов с описанием.

🗑️

Удаление

Чистое удаление установленного плагина одной кнопкой без следов в реестре.

👤

Избранное

Сохраняет список нужных плагинов для быстрого развёртывания на новом месте.

HTML/CSS

Вёрстка статического сайта

Основная работа этапа: сверстать сайт про проект ACM Manager на чистом HTML и CSS без фреймворков. Все разделы собраны на одной странице с навигацией по якорям. Тёмная тема, адаптивность через Grid и Flexbox.


Самое сложное было сделать нормальный дизайн без Bootstrap. Разобрался с CSS-переменными, backdrop-filter и clamp() для адаптивных размеров шрифта.


Что сделано: один index.html со всеми разделами, style.css с тёмной темой, якорная навигация, адаптивность.
